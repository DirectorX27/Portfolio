# Архитектура

## Каркас страницы

```
Page (.page, min-height 100svh, фон --surfacebackground)
└─ .content  flex, gap 80, по центру
   ├─ About   <aside>, 300px, sticky top 0, height 100svh, padding-block 32, gap 32
   │  ├─ .media     AvatarVideo + Clock, gap 4
   │  ├─ Intro      h1 + p, gap 8
   │  ├─ Experience h2 + ul, gap 4
   │  └─ .controls  flex-grow, прижат к низу, gap 20
   │     ├─ ContactButton
   │     └─ .meta   OpenToWork ↔ ThemeToggle (space-between)
   └─ Gallery <main id="gallery">, 560px, sticky, height 100svh (см. «Галерея»)
      ├─ [data-slot="gallery-canvas"]  WebGL-лента
      └─ WorkList                       HTML-список работ
```

Колонка About **sticky** и занимает высоту окна. Когда галерея станет длиннее экрана,
левая часть останется на месте, а прокручиваться будет только правая. Минимальная высота
колонки 640px: ниже кнопка перестаёт прижиматься к низу и не наезжает на контент.

## Данные

| Блок | Источник | Обновление |
|---|---|---|
| Время | `Intl.DateTimeFormat` с `timeZone: 'Europe/Moscow'` | ровно на смене минуты + при возврате во вкладку |
| Погода | Open-Meteo `current=temperature_2m,weather_code,cloud_cover,wind_speed_10m` (без API-ключа); параллельно с ним met.no `locationforecast/2.0/compact` (символ → код WMO), берётся первый ответ, таймаут 6 с | раз в 15 мин, кэш в `localStorage` (`weather:msk:v2`) |
| Небо в часах | `Clock/sky/`: WebGL-шейдер (небо, звёзды, луна с фазой по дате, облака, туман) + 2D-канвас (дождь, снег). Цвет по высоте солнца над Москвой, сцена по коду WMO | солнце раз в 30 с, смена погоды перетекает плавно |
| Тема | `data-theme` на `<html>` | инлайн-скрипт в `index.html` до отрисовки, без вспышки |

Время не зависит от часового пояса устройства: на любом компьютере показывается московское.

Если погода не загрузилась, остаётся последнее значение из кэша, а без кэша выводится `—°C` и ясное небо.
Без WebGL канвасы скрываются и виден плоский фон `--surfaceclock`. Вне экрана небо не рисуется.
Песочница со всеми сценами и переключателем темы: `demos/weather-clock.html`.
Отрицательные значения пишутся с типографским минусом `−`.

Тема: по умолчанию системная (`prefers-color-scheme`). После клика выбор сохраняется
в `localStorage.theme` и дальше важнее системной.

## Анимации и доступность

- Видео аватара: `autoplay muted loop playsInline`.
- Индикатор Open to work: CSS-пульс 1.6 с.
- `prefers-reduced-motion` выключает только дрейф и изгиб WebGL-ленты. Всё остальное (видео, шейдеры,
  смена слова, переходы, звуки) работает: на Windows настройку часто выключают оптимизаторы, и без видео портфолио пустое.
- Часы озвучиваются одной фразой («Moscow, 09:41, 10°C»), сами цифры скрыты от скринридера.
- Логотипы декоративные (`alt=""`): название компании есть рядом текстом.

## Галерея

Бесконечная WebGL-лента по мотивам [Codrops / OGL](https://tympanus.net/codrops/2021/01/05/creating-an-infinite-auto-scrolling-gallery-using-webgl-with-ogl-and-glsl-shaders/).

```
Gallery <main id="gallery" data-mode="webgl|list">
├─ [data-slot="gallery-canvas"]  канвас OGL (только webgl), шире колонки на gallery.bleed
└─ WorkList                       HTML-список: на десктопе скрыт визуально (для скринридеров), иначе виден
```

| Файл | Что делает |
|---|---|
| `src/data/works.ts` | работы из `public/works` (список и размеры — плагин `vite/works.ts`), порядок `order`, ссылки `extras`; подпись — из имени файла |
| `src/config/site.ts` → `gallery` | колонки, отступы, скорость дрейфа, параллакс, изгиб |
| `Gallery/layout.ts` | masonry: работа уходит в колонку с меньшей суммой пропорций |
| `Gallery/webgl/card.ts` | рисует картинку + подпись в 2D-канвас → одна текстура на карточку |
| `Gallery/webgl/GalleryScene.ts` | рендерер, прокрутка, петля, клики |
| `Gallery/webgl/shaders/*.glsl` | изгиб от скорости (vertex), вывод текстуры (fragment) |

Как работает:

- **Режим.** WebGL при ширине ≥ 1040px и поддержке WebGL. Иначе обычный HTML-список с тем же числом колонок.
- **Пропорции.** Берутся из `width/height` в данных, поэтому раскладка известна до загрузки файла.
  Картинка вписывается cover — при верных размерах ничего не обрезается.
- **Подпись** рисуется в ту же текстуру и изгибается вместе с картинкой. `caption.layout`:
  `row` (название слева, meta справа) или `stack` (две строки). Длинный текст обрезается многоточием.
  Ограничение: canvas не умеет `font-variation-settings`, поэтому в подписи Inter без `opsz 32`.
- **Петля.** Каждая колонка зацикливается по своей высоте. Если колонка короче экрана плюс
  самая высокая карточка, набор в ней повторяется.
- **Движение.** Дрейф `autoSpeed` px/с в сторону последней прокрутки. При наведении на ленту
  дрейф плавно останавливается (`driftEase`). Колесо крутит ленту над всей страницей (если окно
  такое низкое, что страница сама прокручивается, — только над галереей). Колесо и перетаскивание
  меняют цель, лента догоняет с `ease`. Скорость считается от времени, не от кадров.
  `columnSpeed` задаёт параллакс колонок.
- **Рамка картинки:** скругление `radius` (32) и обводка `border` 0.8px цветом `--border-divider`,
  как у строк Experience. В WebGL обводку рисует фрагментный шейдер поверх и картинки, и видео,
  в HTML-списке — `::after` поверх медиа.
- **Изгиб** пропорционален скорости, на дрейфе почти незаметен.
- **reduced-motion:** без дрейфа и изгиба, ручная прокрутка остаётся.
- **Тема:** цвета подписи и плашек читаются из токенов, при смене `data-theme` текстуры перерисовываются.
- **Клик** по карточке с `href` открывает ссылку (внешние — в новой вкладке). Перетаскивание кликом не считается.

Добавить работу: положить файл в `public/works/` — и всё. Плагин `vite/works.ts` сам находит файлы,
читает размеры из заголовков (avif, jpg, png, webp, gif, mp4, mov) и в dev перезагружает страницу.
Порядок: файлы из `order` в `works.ts` идут первыми, остальные — после них по алфавиту.
Подпись берётся из имени файла: `Заказчик.Название шота.mp4` → два блока (заказчик, шот) по половине
ширины, `Название шота.mp4` без точки → один блок. Делится по последней точке. Постер видео —
`Заказчик.Название шота.poster.jpg`.
Видео (`.mp4`, `.webm`, `.mov`) крутится без звука по кругу и грузится, только когда карточка
подъезжает к экрану (за экран до появления); за экраном стоит на паузе. В WebGL кадр идёт отдельной
текстурой прямо из `<video>` (по `requestVideoFrameCallback`), карточка с подписью не перерисовывается —
скругление шейдер берёт из её альфы. `poster` — первый кадр, виден до загрузки. Видео играет и при reduced-motion.
Держи видео ~1080px и до 10 МБ.
AVIF не делай через macOS `sips`: Chrome читает у такого файла размер, но рисует пустоту, и карточка
остаётся пустой. Жми через sharp/libavif (`quality` ~80, `chromaSubsampling: '4:4:4'`) — так сохраняется зерно.

на веб-использование.
